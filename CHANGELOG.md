# Changelog

All notable changes to this skill are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-19

### Added
- `board` skill with 8 core seats and 6 situational seats.
- Decision sizing: Quick, Session and Full board.
- Session protocol: commit lines, independent takes, cross-examination, forced dissent, blockers, pre-mortem, Chair synthesis.
- Evidence standard tagging every claim as Fact, Assumption or Judgment.
- Decision log with predictions, tripwires and outcome grading at check-in.
- Full seat briefs in `references/seats.md`.
- Claude Code plugin and marketplace manifests.
